# Project: GreenVerify AI (실제 공공데이터 기반 공정 친환경 검증 및 XAI 윤리 플랫폼) ## 1. 핵심 제약 사항 (Strict Data Policy - 가상 데이터 절대 금지) - **가상 기업(정키화학 등) 및 임의로 생성한 가짜 샘플 데이터를 코드에 절대 포함하지 말 것.** - 모든 분석과 판정은 오직 아래 지정된 **3가지 공식 공공·연구 데이터셋의 실제 구조와 컬럼** 및 **사용자가 직접 업로드하는 실제 CSV/Excel 데이터 파일**만을 기반으로 작동하도록 구현할 것. --- ## 2. 연동 공식 데이터셋 (Official Data Sources) 1. **한국환경산업기술원_환경정보공개시스템_대표사업체 환경 배출량 5개년 정보** - URL: https://www.data.go.kr/data/15101493/fileData.do - 역할: 실제 국내 대표사업체의 연도별 에너지·원료 투입량 및 온실가스·대기오염물질 배출량 데이터를 파싱하여 **1단계 [기계학습 - 선형 회귀]** 표준 기준선 산출에 사용. 2. **Zenodo 공정 및 환경 센서 데이터셋 (Record #18644356)** - URL: https://zenodo.org/records/18644356 - 역할: 실제 공정 시계열 센서 측정치 데이터를 파싱하여 **2단계 [딥러닝 - 인공신경망(ANN)]** 비선형 이상 패턴 감지에 사용. 3. **캐나다 정부 오픈데이터 GHGRP (시설별 온실가스 배출 데이터)** - URL: https://open.canada.ca/data/en/dataset/a8ba14b7-7f23-462a-bdbb-83b0ef629823 - 역할: 실제 해외 산업 시설별 온실가스(CO2eq, CH4, N2O 등) 보고 데이터를 파싱하여 배출량 교차 검증 및 위험 수준 판정에 사용. --- ## 3. 사용자 페르소나 및 AI 윤리 해결 목표 - **사용자 페르소나**: 금정기 (32세, 신소재 공정개발 연구원) - 친환경 신소재를 개발하더라도 실제 생산 공정에서 소비되는 전력과 배출되는 대기오염물질이 환경에 미치는 영향을 실제 데이터로 검증하고 개선 방향을 찾고자 함. - **AI 윤리적 해결 목표 (XAI 투명성)**: - 기존 딥러닝 AI가 결과를 내는 내부 과정을 알 수 없는 **'블랙박스 특성(설명가능성 및 투명성 결여)'**을 해결하기 위해, 특정 기업·시설이 왜 친환경이 아닌지 **대기오염물질 초과 비율(%), 선형회귀 예측 기준치 대비 편차(%) 등 구체적인 수치 근거**를 함께 출력할 것. --- ## 4. 2단계 AI 분석 파이프라인 1. **1단계 [기계학습 - 선형 회귀 (Linear Regression)]**: - 업로드/선택된 실제 데이터셋의 에너지·원료 투입량($X$)과 실제 배출량($Y$) 데이터를 학습하여 회귀식($\hat{Y} = wX + b$)을 실시간으로 계산하고, 기준선 대비 실제 배출량의 초과율(%)을 도출할 것. 2. **2단계 [딥러닝 - 인공신경망 (ANN)]**: - 선형 회귀가 포착하지 못하는 연속적인 센서/배출 데이터의 비선형 이상 패턴과 급증 구간을 탐지할 것. 3. **3단계 [설명가능한 AI (XAI) 근거 산출]**: - 각 오염물질(온실가스, NOx, SOx, 미세먼지 등)이 전체 위험도에 기여한 비중(%)을 계산하여 블랙박스 없는 투명한 판정 사유를 생성할 것. --- ## 5. 필수 화면 및 기능 요구사항 1. **실제 데이터 파일(CSV/JSON) 업로더 및 데이터셋 선택기**: - 가상 더미 데이터 대신, 사용자가 공공데이터포털(`data.go.kr`), `Zenodo`, `캐나다 GHGRP`에서 내려받은 **실제 CSV 파일을 드래그 앤 드롭으로 업로드하면 즉시 컬럼을 인식해 분석하는 파서(PapaParse 등) 기능**을 최상단에 구현할 것. - 각 공식 데이터셋(3종)의 다운로드 원문 링크 바로가기 버튼 제공. 2. **기업·시설 검색 및 위험 수준 대시보드**: - 업로드된 실제 데이터 내의 기업명·시설명을 검색하여 선택하면 해당 사업체의 실제 온실가스 배출량과 대기오염물질 수치를 표시하고 위험 수준(`안전 / 주의 / 위험 / 심각`)을 판정할 것. 3. **최종 친환경 판정 및 XAI 근거 리포트**: - `[친환경 적합]` 또는 `[친환경 부적합]` 최종 판정 배너. - 모호한 판정 대신 **"선형회귀 예측 기준치 대비 온실가스 +XX.X% 초과"**, **"대기오염물질 중 NOx 비중이 XX.X%로 가장 높음"** 등 실제 계산된 퍼센트(%) 근거와 기여도 가로 막대그래프 시각화. 4. **공정 개선 시뮬레이터**: - 선택된 실제 기업 데이터의 에너지 투입량 및 오염물질 저감률을 슬라이더로 조절하여, 선형회귀 기준치 이하로 내려가는 개선 목표치를 실시간 시뮬레이션. - **언어**: 모든 UI, 안내 문구, XAI 분석 리포트는 자연스러운 **한국어**로 구현할 것.
